## 🎓 **How to Use New Features**

### 1. **SMS Integration**
```javascript
import { sendSMS, sendWelcomeSMS } from './services/smsService.js';

// Send SMS
await sendSMS('+919876543210', 'Your message here');

// Send welcome SMS
await sendWelcomeSMS(lead);
```

### 2. **WhatsApp Integration**
```javascript
import { sendWhatsApp, sendWelcomeWhatsApp } from './services/whatsappService.js';

// Send WhatsApp
await sendWhatsApp('+919876543210', 'Your message here');

// Send welcome WhatsApp
await sendWelcomeWhatsApp(lead);
```

### 3. **UTM Tracking**
```javascript
// Track UTM parameters (from frontend)
await fetch('/api/utm/track', {
  method: 'POST',
  body: JSON.stringify({
    utm_source: 'google',
    utm_medium: 'cpc',
    utm_campaign: 'summer_2026',
    landing_page: '/courses/mba'
  })
});

// Get analytics
const analytics = await fetch('/api/utm/analytics?date_from=2026-01-01');
```

### 4. **Lead Distribution**
```javascript
// Create distribution rule
await fetch('/api/lead-distribution', {
  method: 'POST',
  body: JSON.stringify({
    name: 'MBA Leads to Senior Counselors',
    priority: 1,
    conditions: { course: 'MBA', source: 'Website' },
    assignment_type: 'least_loaded',
    counselor_ids: ['counselor1', 'counselor2']
  })
});
```

### 5. **Video Counseling**
```javascript
import { createZoomMeeting } from './services/zoomService.js';

// Create Zoom meeting
const meeting = await createZoomMeeting({
  topic: 'MBA Counseling - Rahul Sharma',
  start_time: '2026-06-15T10:00:00Z',
  duration: 30,
  agenda: 'Discuss MBA program details'
});

console.log(meeting.join_url); // Share with student
```

### 6. **Document OCR**
```javascript
import { extractDocumentFields } from './services/ocrService.js';

// Extract fields from marksheet
const result = await extractDocumentFields('/path/to/marksheet.jpg', 'marksheet');
console.log(result.fields); // { name, roll_number, percentage, grade, year }
```

### 7. **Multi-Language**
```javascript
// Get translations
const translations = await fetch('/api/i18n/translations?lang=hi');

// Set user language
await fetch('/api/i18n/user/language', {
  method: 'PUT',
  body: JSON.stringify({ language: 'hi' })
});
```
